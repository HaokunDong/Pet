# 需求文档：宠物培养系统

## 引言

宠物培养系统是一个角色成长机制，允许玩家通过积累经验值来提升宠物等级，每次升级获得天赋点，然后将天赋点分配到不同的属性加成选项中，从而增强角色的战斗能力。该系统包含一个完整的 UI 界面和对应的数据逻辑，与现有的 `RuntimeCharacterStats` 系统集成，实时影响角色的战斗属性。

## 需求

### 需求 1：等级与经验值系统

**用户故事：** 作为一名玩家，我希望我的宠物能够通过积累经验值来升级，以便感受到角色的成长进度。

#### 验收标准

1. WHEN 宠物获得经验值 AND 经验值达到当前等级所需的经验上限 THEN 系统 SHALL 自动将宠物等级+1，并将溢出的经验值累计到下一级。
2. WHEN 宠物升级 THEN 系统 SHALL 给予玩家1个天赋点。
3. IF 宠物当前等级为1级且经验值为0 THEN 系统 SHALL 显示空的经验进度条。
4. WHEN 经验值发生变化 THEN UI SHALL 实时更新经验进度条的填充比例（当前经验/升级所需经验）。
5. WHEN 宠物等级发生变化 THEN UI SHALL 实时更新等级显示数字。
6. 系统 SHALL 定义每级升级所需经验值的公式（如：所需经验 = 基础经验 × 等级^增长系数），可在配置中调整。

### 需求 2：天赋点系统

**用户故事：** 作为一名玩家，我希望每次升级获得天赋点，以便我可以自由选择强化哪些属性。

#### 验收标准

1. WHEN 宠物升级 THEN 系统 SHALL 增加1个可用天赋点。
2. WHEN 玩家点击某个属性的升级按钮 AND 可用天赋点 > 0 THEN 系统 SHALL 消耗1个天赋点并提升对应属性加成等级+1。
3. IF 可用天赋点为0 THEN 系统 SHALL 禁用所有升级按钮（灰显不可点击）。
4. WHEN 天赋点数量发生变化 THEN UI SHALL 实时更新天赋点显示数字。

### 需求 3：属性加成选项

**用户故事：** 作为一名玩家，我希望能够将天赋点投入到不同的属性加成中，以便根据我的战斗风格定制角色能力。

#### 验收标准

1. 系统 SHALL 提供以下6个属性加成选项，每个选项独立计算等级：
   - 攻击加成：每级提升 x% 攻击力
   - 防御加成：每级提升 x% 防御力
   - 生命加成：每级提升 x% 生命值
   - 攻速加成：每级提升 x% 攻击速度
   - 移速加成：每级提升 x% 移动速度
   - 技能冷却速度加成：每级提升 x% 技能CD减少

2. WHEN 玩家点击某属性的升级按钮 THEN 系统 SHALL 将该属性加成等级+1，并立即重新计算角色的实际属性值。
3. WHEN 属性加成等级变化 THEN UI SHALL 更新该选项显示的当前等级和百分比加成数值。
4. 系统 SHALL 将属性加成以百分比方式叠加到角色的基础属性上（最终属性 = 基础属性 × (1 + 加成等级 × 每级百分比)）。
5. 每级百分比加成值 SHALL 可在配置中调整（如每级5%攻击力加成）。

### 需求 4：培养系统 UI 界面

**用户故事：** 作为一名玩家，我希望有一个清晰直观的培养界面，以便我能方便地查看宠物状态并进行属性升级操作。

#### 验收标准

1. UI 界面 SHALL 从上到下依次包含以下元素：
   - 等级显示（如 "Lv. 5"）
   - 天赋点显示（如 "天赋点: 3"）
   - 经验值进度条（显示当前经验/所需经验，如 "120/200"）
   - 攻击加成选项行（显示当前等级、加成百分比、升级按钮）
   - 防御加成选项行
   - 生命加成选项行
   - 攻速加成选项行
   - 移速加成选项行
   - 技能冷却速度加成选项行

2. WHEN 玩家点击角色身上弹出的"培养"按钮（CharacterButtonPanel 中的 Train 按钮） THEN 系统 SHALL 打开培养界面（CultivationPanel），并关闭按钮面板。
3. WHEN 培养界面打开 THEN 系统 SHALL 显示当前角色的所有培养数据。
4. WHEN 玩家点击培养界面的关闭按钮 THEN 系统 SHALL 关闭培养界面，并恢复角色之前的控制模式。
5. WHEN 可用天赋点为0 THEN 所有升级按钮 SHALL 显示为灰色不可点击状态。
6. WHEN 可用天赋点 > 0 THEN 升级按钮 SHALL 显示为高亮可点击状态。
7. 每个属性选项行 SHALL 显示：属性名称、当前加成等级、当前加成百分比值、升级按钮（标注"+1"）。
8. 培养界面打开期间，角色 SHALL 保持暂停状态（不执行 AI 行为或手动操控）。

### 需求 5：数据持久化

**用户故事：** 作为一名玩家，我希望培养进度能够被保存，以便下次打开游戏时不会丢失升级数据。

#### 验收标准

1. WHEN 游戏保存 THEN 系统 SHALL 将宠物的等级、经验值、天赋点、各属性加成等级保存到存档文件中。
2. WHEN 游戏加载 THEN 系统 SHALL 从存档文件中恢复宠物的培养数据，并重新计算属性加成。
3. 培养数据 SHALL 与现有的 `SaveManager` 系统集成，使用相同的 JSON 序列化方式。

### 需求 6：经验值获取

**用户故事：** 作为一名玩家，我希望通过击败敌人来获得经验值，以便我的宠物能够在战斗中成长。

#### 验收标准

1. WHEN 玩家角色击败一个敌人 THEN 系统 SHALL 给予玩家角色一定量的经验值。
2. 经验值奖励数量 SHALL 可在敌人的 `CharacterData` 中配置（如 `expReward` 字段）。
3. IF 敌人没有配置经验值奖励 THEN 系统 SHALL 使用默认值（如10点经验）。

## 技术约束

- 培养数据需要与现有的 `RuntimeCharacterStats` 系统集成，属性加成在运行时动态计算
- UI 使用 Unity 的 UGUI 系统（Canvas + RectTransform），与现有的 Canvas 结构兼容
- 数据持久化使用现有的 `SaveManager` + JSON 序列化方式
- 培养数据应作为 ScriptableObject 配置（升级经验公式、每级加成百分比等）
- 需要考虑角色切换时培养数据的独立性（每个角色有自己的培养进度）

## 边界情况

- 经验值溢出：一次获得大量经验可能连升多级，需要循环处理
- 角色切换：切换角色时需要正确加载/卸载对应的培养数据
- 属性上限：是否需要设置属性加成的最大等级（防止无限堆叠）
- 等级上限：是否需要设置最大等级
